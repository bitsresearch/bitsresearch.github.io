BITS Completion Letter - Rise Download Version v13

Changes in v13:
- Removed the Open PDF button.
- Save PDF remains the only learner action.
- Generated PDFs now use the PDF Standard Security Handler (128-bit RC4, Revision 3).
- No password is required to open the PDF.
- Printing and high-quality printing are allowed.
- Editing/document modification, copying, annotations, form filling and page assembly are restricted in conforming PDF readers.
- A random owner password is generated for every PDF and is never shown to the learner.

Important: PDF permission restrictions are not unbreakable DRM. Software that deliberately ignores PDF permissions may still alter a document.
